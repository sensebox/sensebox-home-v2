    2. Result

    Send the config to the box with the serial monitor of the Arduino IDE:

    1. Connect the box over USB and open the Arduino IDE.
    2. Choose the board's port under Tools → Port, then open Tools → Serial Monitor.
    3. In the serial monitor, set 115200 baud and the line ending New Line.
    4. Copy each command below, paste it into the input field of the serial monitor and press Enter. Wait for the answer before you send the next one.
